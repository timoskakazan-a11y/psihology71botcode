# Бот анонимной психологической поддержки

Серверлес Telegram-бот (Telegraf + TypeScript, на Vercel Functions), который
принимает анонимные обращения в личных сообщениях и пересылает их в групповой
чат психологов, откуда можно ответить анонимному автору.

## Как это устроено

- `api/webhook.ts` — вся логика бота (команды, кнопки, пересылка сообщений).
- `api/notify.ts`, `api/publish.ts` — вспомогательные эндпоинты для отправки
  произвольных уведомлений/постов через бота.
- `api/setup.ts` — серверная установка Telegram webhook (токен остаётся на
  сервере, а не в браузере).
- `lib/db.ts` — вся работа с Supabase: тикеты, сообщения, привязка чата
  психологов, блокировки.

### Почему привязка чата теперь не слетает

Раньше ID чата психологов и список заблокированных пользователей хранились
**в памяти процесса**. Netlify/serverless-функции могут в любой момент поднять
новый инстанс с чистой памятью (и почти всегда поднимают — под нагрузкой
работает сразу несколько параллельных копий функции), поэтому привязка
случайным образом "терялась". Теперь она хранится в Supabase и читается из
базы при каждом входящем сообщении — она переживает холодный старт, редеплой
и что угодно ещё.

### Почему сообщения теперь не мешаются между собой

У каждого обращения есть номер тикета (`#123`). Любое сообщение бота в чате
психологов (карточка обращения, приглашение ответить, сам ответ психолога)
записывается в таблицу-карту `psy_message_map`. Когда психолог отвечает через
Telegram "Reply" — неважно, на исходную карточку, на приглашение ответить или
на чей-то предыдущий ответ — бот всегда однозначно находит нужный тикет по
этой карте, а не пытается угадать его по тексту сообщения. Обычное сообщение
без Reply в чате психологов бот больше не пытается интерпретировать — это и
было источником путаницы.

### Анонимность

Бот не показывает психологам имя пользователя и ссылку на профиль — только
номер обращения. Ответить пользователю можно только через тикет.

## Настройка (Vercel)

1. Установите зависимости: `npm install`
2. Скопируйте `.env.example` в `.env.local` и заполните (для локальной
   разработки) — а в проде задайте те же переменные в Vercel: **Project →
   Settings → Environment Variables** (для Production и Preview):
   - `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather.
   - `TELEGRAM_WEBHOOK_SECRET` — произвольная случайная строка (необязательно,
     но защищает вебхук от чужих запросов).
   - `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` — из настроек вашего проекта
     Supabase (Project Settings → API). **Service role key — секрет**, его
     нельзя публиковать и передавать в браузер.
3. Задеплойте на Vercel (проект уже привязан к этому GitHub-репозиторию —
   деплой запускается автоматически на каждый push в `main`).
4. Откройте сайт и нажмите «Подключить Webhook» — это привяжет Telegram к
   `/api/webhook`.
5. Добавьте бота в группу психологов и отправьте там `/send` (от имени
   администратора группы) — теперь все обращения будут приходить сюда.
6. `/status` в любой момент показывает, к какому чату привязан бот и сколько
   открытых обращений.

⚠️ **Важно:** старый токен бота был захардкожен прямо в коде (в том числе в
клиентском React-бандле) и попал в публичный git-репозиторий — его нужно
считать скомпрометированным. Получите новый токен через @BotFather
(`/revoke` у старого или просто `/token` для перегенерации) и используйте
только его в переменных окружения.

## Запуск локально

**Требования:** Node.js

```
npm install
npm run dev
```
